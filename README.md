# Hi, I'm Syed

I build websites, small business tools, brand systems, and the kind of home lab infrastructure that teaches you how things really work.

Most of my recent work sits between polished front-end builds and practical operations: React/Vite sites, responsive layouts, Playwright checks, Docker services, monitoring, private networking, and clean project packaging for real clients or future buyers.

For website builds, templates, automation, or customer work, visit [World Softwares](https://worldsoftwares.com).

## What I'm Working On

- Building small business websites and product concepts that can be shown, tested, and handed off cleanly
- Shaping restaurant and local-business demo apps with menu browsing, mock checkout flows, install guidance, and owner-facing sales screens
- Developing a Raspberry Pi 5 homelab with Docker Compose, a custom Home Portal and Control Center, media automation, retro gaming, and private networking
- Improving reliability through DNS diagnostics, incident tracking, encrypted backups, restore drills, guarded updates, and verified Discord notifications
- Turning older design/graphics work into cleaner modern web showcases
- Exploring Cinema 4D, Redshift, PBR materials, and product-style visuals

## Recent Updates

- **Home Pi Infrastructure:** expanded the Pi 5 into a multi-stack homelab with a mobile-friendly service portal, authenticated administration, self-hosted AIOStreams for Stremio, media delivery, RomM, encrypted recovery, and daily health reporting.
- **Best Wings N Pies:** a restaurant ordering MVP demo with menu customization, cart review, mock checkout pricing, admin-demo state, public demo QA, and clear no-real-payment guardrails.
- **Harbor Halal Platters:** a fictional halal platter storefront demo with QR menu launch, platter customization, local favorites/reorder, checkout preview, install guidance, and static owner-preview screens.
- **CF Auto Care Admin Foundation:** a private auto-service operations build with admin dashboard work, intake, customer/vehicle records, service records, oil-change tracking, and invoice surfaces.
- **Masjid Fatima Website Draft:** a mosque website rebuild concept with multilingual visitor paths, prayer-time continuity, donation/media links, and a staff dashboard foundation.
- **Aliz Studio:** an appointment-based barbershop site with a premium homepage, service packaging, booking flow, mock deposit checkout, and owner dashboard work.
- **TECHNOseller Portal:** a vendor marketplace concept with searchable listings, vendor profiles, buyer lead capture, and moderation workflows.
- **Cloud Website and Web Resume:** older front-end foundations refreshed with screenshot-backed presentation and World Softwares inquiry routing.

## Home Lab / DevOps

Built and operated a Raspberry Pi 5 homelab that has supported 20 containers across infrastructure, media, gaming, and streaming Compose projects, alongside systemd-managed services. Dedicated system, media, backup, and retro-library drives connect through a powered USB hub. The capabilities below describe implemented work, rather than a live uptime report.

<table>
  <tr>
    <td width="50%" valign="top">
      <h3>Pi 5 Service Platform</h3>
      <p>Built a Debian-based Docker Compose environment for everyday home services, moving the media workflow off the main PC. Portainer and container health checks provide service visibility.</p>
      <p><strong>Relevant work:</strong> Linux, Docker Compose, systemd, application migration, storage mounts, service validation.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Home Portal and Control Center</h3>
      <p>Created a mobile-friendly service index with live health badges, storage statistics, interactive previews, incident history, and an installable offline shell. An authenticated Control Center handles approved maintenance and recovery actions.</p>
      <p><strong>Relevant work:</strong> JavaScript, Python, responsive UI, PWA caching, Caddy, authentication, Playwright QA.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Monitoring and Incident Reporting</h3>
      <p>Combined Netdata, Node Exporter, and custom telemetry for container health, disk capacity, USB resets, filesystem errors, cooling, and DNS failures. Daily Discord reports, grouped incident alerts, recovery notices, and a change journal make the system easier to follow.</p>
      <p><strong>Relevant work:</strong> observability, incident lifecycle tracking, alert deduplication, log classification, notification delivery checks.</p>
    </td>
    <td width="50%" valign="top">
      <h3>DNS Reliability and Private Access</h3>
      <p>Built encrypted DNS forwarding with <code>ctrld</code>, NextDNS, and fallback resolvers, plus CoreDNS for local service aliases. Active probes help distinguish resolver failures from local network problems; Tailscale provides private remote access.</p>
      <p><strong>Relevant work:</strong> encrypted DNS, failover diagnostics, split DNS, Caddy routing, Tailscale, firewall policy.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Media Delivery and Library Automation</h3>
      <p>Integrated Plex, Seerr, Sonarr, Radarr, Prowlarr, Bazarr, qBittorrent, and SABnzbd. Built a phone-friendly TorBox queue with flexible search, batch selection, duplicate checks, transfer progress, retries, and Plex delivery verification. Watched-media cleanup includes a grace period and a preview of pending items.</p>
      <p><strong>Relevant work:</strong> API integration, durable background jobs, media imports, VPN-isolated downloads, safe retention workflows.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Retro Library and Game Streaming</h3>
      <p>Deployed RomM for a catalogued ROM collection, browser-based play, and controller-enabled clients. Added duplicate review and monitored CHD compression workflows, alongside a separate Moonlight streaming path for remote play.</p>
      <p><strong>Relevant work:</strong> RomM, library organization, storage optimization, controller troubleshooting, remote gaming.</p>
    </td>
  </tr>
  <tr>
    <td width="50%" valign="top">
      <h3>Encrypted Backup and Recovery</h3>
      <p>Implemented Restic backups of configuration and application state to a separate drive, scheduled repository checks, sample restores, and isolated restore drills. A recovery runbook, portable pack without credentials, and move-readiness workflow support rebuilding and relocating the lab. Bulk media is separate from this backup scope.</p>
      <p><strong>Relevant work:</strong> encrypted snapshots, retention, integrity verification, recovery documentation, restore testing.</p>
    </td>
    <td width="50%" valign="top">
      <h3>Guarded Maintenance and Administration</h3>
      <p>Added package, container, and OpenClaw update controls with activity and storage checks, backup gates, and post-update health verification. Failed container-stack checks can restore saved images; post-boot checks verify essential services. Privileged web actions use a narrow helper allowlist.</p>
      <p><strong>Relevant work:</strong> least-privilege administration, controlled updates, container rollback, post-boot recovery, audit trails.</p>
    </td>
  </tr>

Self-hosted AIOStreams on the Pi using Docker Compose and a Cloudflare Tunnel for remote HTTPS access from Stremio. Integrated add-on aggregation, catalogues, provider accounts, and stream filtering, with monitoring that distinguishes application and tunnel failures from upstream provider errors. OpenClaw is part of the lab's agent tooling; maintenance permissions remain explicitly controlled.
