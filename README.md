# Hi, I'm Syed

I build websites, small business tools, brand systems, and the kind of home lab infrastructure that teaches you how things really work.

Most of my recent work sits between polished front-end builds and practical operations: React/Vite sites, responsive layouts, Playwright checks, Docker services, monitoring, private networking, and clean project packaging for real clients or future buyers.

For website builds, templates, automation, or customer work, visit [World Softwares](https://worldsoftwares.com).

## What I'm Working On

- Building small business websites and product concepts that can be shown, tested, and handed off cleanly
- Running a home lab with Raspberry Pi services, Docker, Portainer, Grafana, Node Exporter, Tailscale, and encrypted DNS
- Staging a Raspberry Pi 5 before replacing a production Raspberry Pi 3B, with monitoring and rollback thinking baked in
- Turning older design/graphics work into cleaner modern web showcases
- Exploring Cinema 4D, Redshift, PBR materials, and product-style visuals
